# Рубликс — сайт

Запуск всего проекта: `npm ci && npm start` из корня репозитория.
Инструкция и описание — в [README](../README.md).

Для реальных котировок нужен сервер проекта, даже в гостевом режиме.
Статический сервер не предоставляет `/api/market`: без него рынок будет недоступен,
а обучение и локальные игры продолжат работать. Открывайте сайт через HTTP.

- `index.html` — экраны и режимы `RUBLIKS_LOCAL_ONLY`, `RUBLIKS_GUEST_ONLY`.
- `css/style.css` — адаптивная вёрстка телефона и ПК.
- `css/design.css` — базовая сетка, иерархия главной и навигация.
- `css/teen.css` — единая тема, формы, профиль, настройки и редактор внешности.
- `css/play.css`, `css/learning.css` — игровые состояния и учебные миссии.
- `js/avatar.js` — оригинальный персонаж, одежда, причёски и эмоции.
- `js/app.js` — навигация, сделки, игры и отображение.
- `js/data.js` — учебные материалы и localStorage с ключами по пользователю.
- `js/api.js` — котировки и свечи через серверный шлюз MOEX, без автоматических демо-цен.
- `js/learning.js` — шесть миссий, проверки понимания и прогресс.
- `js/auth-api.js` — серверные аккаунты, портфель и друзья.
- `js/chart.js`, `vendor/` — графики Lightweight Charts и локальные библиотеки.
- `js/db.js` — совместимость с прежним браузерным SQLite; текущий прогресс хранится в localStorage.

Тарифы переключаются без оплаты. Миссии и ситуации в играх — учебные,
друзья гостя — примеры. Цены и параметры торгов получаются с биржи,
полный стакан требует отдельного доступа, дивиденды не начисляются.
Покупки и продажи виртуальные.
Для серверных аккаунтов отключите оба флага в HTML; используйте сервер проекта.
Сервер синхронизирует портфель и статистику, остальные настройки остаются в браузере.
