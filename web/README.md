# Рубликс — сайт

Запуск всего проекта: `npm ci && npm start` из корня репозитория.
Инструкция и описание — в [README](../README.md).

Для гостевого демо достаточно статического сервера:
`python3 -m http.server 8080 --directory web` из корня.
Открывайте сайт через HTTP, чтобы данные браузера сохранялись предсказуемо.

- `index.html` — экраны и режимы `RUBLIKS_LOCAL_ONLY`, `RUBLIKS_GUEST_ONLY`.
- `css/style.css` — адаптивная вёрстка телефона и ПК.
- `js/app.js` — навигация, сделки, игры и отображение.
- `js/data.js` — учебные материалы и localStorage с ключами по пользователю.
- `js/api.js` — MOEX ISS с тайм-аутом и учебными данными при ошибке.
- `js/auth-api.js` — серверные аккаунты, портфель и друзья.
- `js/chart.js`, `vendor/` — графики Lightweight Charts и локальные библиотеки.
- `js/db.js` — совместимость с прежним браузерным SQLite; текущий прогресс хранится в localStorage.

Тарифы переключаются без оплаты. Новости, дивиденды, показатели эмитентов и
друзья гостя — учебные данные. Покупки и продажи виртуальные.
Для серверных аккаунтов отключите оба флага в HTML; используйте сервер проекта.
Сервер синхронизирует портфель и статистику, остальные настройки остаются в браузере.
