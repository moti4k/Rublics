## Промпт для Figma Make (вставить целиком)

```
Создай UI-kit и набор экранов мобильного веб-приложения «Рубликс» — финансово-инвестиционный симулятор для подростков и начинающих. Не копируй логотипы и бренды конкурентов (Тинькофф, Сбер и т.д.); вдохновляйся ритмом финтех-приложений: карточки, скругления, чёткая иерархия, нижняя навигация.

Бренд-палитра (строго):
- Primary / акцент действия: #E9110B
- Violet / вторичный бренд, заголовки, графики: #522C80
- Yellow / акцентные вставки: #FFCA04
- Фон UI / холсты: #F7F7F5
- Текст основной: #000000, вторичный: серый
- Успех / рост: #22C55E, ошибка: #EF4444, предупреждение: #F59E0B, инфо: #3B82F6
- Белый: #FFFFFF

Тон коммуникации: дружелюбный, без снобизма, короткие фразы, юмор допустим; обязательные дисклеймеры: это обучение и демо, не инвестиционная рекомендация, валюта и портфель игровые.

Навигация: нижний таб-бар на 5 пунктов — Главная, Игры, Обучение, Друзья, Профиль. Многие экраны открываются поверх без таб-бара (модалки, график бумаги, покупка, аналитика).

Сделай макеты в едином стиле: карточки портфеля, чипы инструментов, сторис-полоса, списки акций с % изменения за день, табы на экране бумаги (Обзор | Стакан | Дивиденды | Новости | События), первичные кнопки градиентом primary, вторичные — outline violet.

Экраны для отрисовки (приоритет):
1) Авторизация: регистрация / вход по email
2) Онбординг + входной тест уровня + экран результата (новичок / исследователь / профи)
3) Главная: поиск, сторис, карточка оценки портфеля с переключателем «За день / За всё время», чип активного счёта, деньги на счёте, быстрые действия «Операции» и «Аналитика» (без кнопки «Пополнить» — это не реальные деньги), чипы инструментов (акции активны, остальное disabled), топ движений по бирже, карусель новостей, сетка тем обучения, блок позиций в портфеле; подвкладки «Главная» / «Избранное»
4) Список всех акций с сортировкой (по движению / по алфавиту)
5) Экран бумаги: шапка с тикером, избранное, шаринг, табы, график свечей, описание эмитента, купить/продать; вкладки стакан (две колонки bid/ask), дивиденды таблицей, новости списком, события — лента сделок по тикеру
6) Покупка: доступный баланс, выбор счёта (если несколько), тикер, количество, итого, кнопка купить
7) Продажа: список позиций, шит количества
8) Аналитика: сводка по активному счёту и по всем счетам, круговая структура акций, список дневных снимков стоимости, образовательная подсказка
9) Операции: журнал операций, блок про заявки (в демо только рыночные)
10) Игры: сетка карточек игр с иконками
11) Обучение: уроки списком, экран темы с текстом и фактами
12) Друзья: рейтинг по балансу / урокам / квизам
13) Профиль: имя, уровень инвестора, подписка, персонаж, достижения
14) Модалка выбора счёта портфеля + кнопка нового счёта (игровые рубли)
15) Викторина, квиз, мини-игры — отдельные полноэкранные состояния

Формат: iPhone 15 Pro frame, светлая тема, 8pt grid, скругления карточек **20–24px**, мягкие диффузные тени, шрифт **Plus Jakarta Sans** (как на вебе). Нижняя навигация — плавающая капсула с blur. Добавь пустые состояния и состояния загрузки для стакана и графика.
```

## Продукт: цель и что уже сделано

**Название:** Рубликс Web  
**Суть:** Образовательное веб-приложение с **демо-портфелем** (игровые рубли), котировками с Московской биржи (MOEX) где возможно, уроками, играми и социальным рейтингом друзей. Целевая аудитория — **подростки и новички**; фокус на понятных механиках, а не на «настоящем брокере».

**Уже реализовано в коде (для дизайнера — это «истина» по составу UI):**
- Регистрация/вход (email), синхронизация портфеля с бэкендом при наличии API.
- **Мультипортфели:** несколько игровых счетов, переключение в модалке, при покупке — выбор счёта.
- Главная с портфелем, топом движений (сортировка по силе дневного %), новостями, темами, сторис.
- Экран бумаги с графиком (TradingView lightweight-charts), табами обзор / стакан / дивиденды / новости / события.
- Покупка и продажа (рыночная логика в демо).
- Аналитика и операции (журнал сделок).
- Игры: викторина рынка, квиз, финансовый выбор, раннер, rug pull симулятор.
- Профиль, друзья, отчёт для родителя, список новостей и статья.

**Намеренно нет:** кнопки «Пополнить» реальными деньгами — везде подчёркивается игровой/учебный характер.

## Дизайн-система (детализация)

| Токен | HEX | Применение |
|--------|-----|------------|
| Primary | `#E9110B` | CTA, важные акценты, «купить» |
| Violet | `#522C80` | Заголовки, вторичные кнопки, брендовые плашки |
| Yellow | `#FFCA04` | Сторис, акценты, не перегружать |
| Grey UI | `#F7F7F5` | Фон экрана, инпуты, карточки на фоне |
| Text | `#000` / `#757575` | Основной и подписи |
| Success | `#22C55E` | Рост цены, успех |
| Error | `#EF4444` | Падение, ошибки |

**Референс по настроению (не копировать графику):** современные финтех-онбординги и академии трейдинга — **карточный** layout, **горизонтальные** сторис, **чипы** и **pill-переключатели**, плотный но читаемый список инструментов.

**Иллюстрации:** персонаж/аватар в квизе и профиле; игры с простыми иконками (график, мозг, идея, бег, монета).

## Каталог экранов (описание для макетов)

### Вне основного приложения
| Экран | Назначение | Ключевые элементы |
|--------|------------|-------------------|
| **Auth** | Регистрация / вход | Табы, формы email/пароль/имя, ошибки сети |

### Онбординг и тест
| Экран | Назначение | Ключевые элементы |
|--------|------------|-------------------|
| **Onboarding** | Первый заход | Слоган, CTA «начать» |
| **Entrance test** | 6 вопросов | Карточки ответов, **прогресс-бар** |
| **Entrance result** | Уровень: новичок / исследователь / профи | Заголовок, текст, кнопка в приложение |

### Нижнее меню: Главная
| Экран | Назначение | Ключевые элементы |
|--------|------------|-------------------|
| **Home** | Хаб | Поиск; сторис; карточка портфеля (оценка, чип **названия счёта**, «деньги на счёте», pill день/всё время, **2 быстрых круга**: Операции, Аналитика); чипы инструментов; топ-5 движений; карусель новостей; чипы акций; сетка тем; блок «В портфеле» |
| **Home → Избранное** | Тикеры из ☆ | Список с ценой и % дня |

### Рынок и сделки
| Экран | Назначение | Ключевые элементы |
|--------|------------|-------------------|
| **Все акции** | Каталог TQBR | Поиск с главной, сортировка «движение / А–Я», строки тикер+имя+цена+% |
| **Бумага (chart)** | Карточка инструмента | Назад; название; тикер; ☆; шаринг; **5 табов**; обзор: цена, изменение дня, таймфреймы, график, объём, «о бумаге», Купить/Продать; остальные табы — контент-панели |
| **Покупка** | Сделка | Отмена; доступно ₽; **селект счёта** (если >1); тикер; qty; итого; купить |
| **Продажа** | Выход из позиций | Список акций/крипты, кнопка продать, bottom sheet количества |

### Аналитика и журнал
| Экран | Назначение | Ключевые элементы |
|--------|------------|-------------------|
| **Аналитика** | Сводка | Назад; активный счёт; оценка; сумма по всем счетам; **круг** долей акций; список снимков «день → сумма»; текст-подсказка |
| **Операции** | История | Назад; хронология покупок/продаж; текст про лимитные заявки (в планах) |

### Обучение и контент
| Экран | Назначение | Ключевые элементы |
|--------|------------|-------------------|
| **Education** | Уроки | Список карточек уроков (длительность, ссылка) |
| **Topic** | Тема | Заголовок, абзацы, факты, CTA «купить» где уместно, ссылка на акции |
| **News** | Список статей | Строки с датой |
| **Article** | Чтение | Заголовок, подзаголовок, мета, текст, источник |

### Игры
| Экран | Назначение | Ключевые элементы |

### Соц и профиль

## Бэклог дизайна (ещё не в продукте — можно заложить в UI-kit)
