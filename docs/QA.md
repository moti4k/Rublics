# Проверка сайта — 1 ноября 2026

Локально пройдены 44 проверки Playwright: Chrome 1440×1000, Android Pixel 7,
WebKit iPhone 15, узкий экран 320×640. Критические сценарии покупки/продажи
и изоляции данных дополнительно повторены по пять раз.

Покрытие: входной тест, навигация, статьи, все игровые экраны, прохождение квиза
и финансового выбора, результат викторины, возобновление раг пула, запуск раннера,
покупка/продажа, сохранение после обновления, графики и вкладки бумаги,
подгрузка истории, имя и тариф профиля, дополнительные счета, аналитика,
клавиатура в модальных окнах, серверная регистрация и восстановление портфеля.
Дополнительно проверено отсутствие декоративных градиентов и явное отключение
не реализованных инструментов. Основные иконки действий заменены на SVG.
Обновлён дизайн: портфель первым на главной, боковая навигация на ПК,
однотонные карточки и единая типографика. Дополнительная проверка адаптивности
охватывает ширины 320, 393, 768, 900, 1024 и 1440 px.
API отдельно проверен на некорректный ввод, сохранение портфеля и выход.

`npm ci`, синтаксическая проверка JavaScript и `npm audit --omit=dev` проходят;
известных уязвимостей зависимостей на момент проверки не найдено.
GitHub Actions настроен, но его облачный запуск состоится после push.

Браузерные тесты отключают внешние котировки для воспроизводимой проверки
учебного fallback. Доступность MOEX, YouTube и Google Fonts зависит от сети.
Проверка мобильных устройств — эмуляция браузеров, не запуск на физических телефонах.
Внешние уроки ведут на поиск видео по теме; содержание сторонних роликов не проверялось.
Друзья гостя, показатели эмитентов, новости и тарифы являются демонстрацией.

iOS-прототип сохранён как отдельная часть проекта. Его сборка в текущем окружении
блокируется несовместимостью CoreSimulator и SDK Xcode; веб-проверки её не подтверждают.
