# Визуальные референсы

Скриншоты, присланные в Cursor (T-Bank, Сбер-инвестиции, Trading Academy, онбординг, «комната героя» и т.д.), сохранены в каталоге проекта Cursor как `assets/image-*.png`.

**Как использовать:** ориентир по композиции (карточки портфеля, сторис, табы бумаги, прогресс в опросе), **без** копирования чужих логотипов и торговых марок.

Вёрстка Рубликс опирается на токены в `web/css/style.css` (`:root`: violet `#522C80`, primary `#E9110B`, yellow `#FFCA04`, grey `#F7F7F5`).
