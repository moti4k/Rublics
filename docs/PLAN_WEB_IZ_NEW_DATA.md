## Часть A. Экраны из «основных правок по MVP»

### Уже близко к описанию (веб сейчас)

- **Главная:** новости/материалы, портфель + изменение за день, топ движений, обучение, мини-игры, шорткаты — *есть*, можно наращивать «сторис» и квесты.
- **Онбординг:** слоган «РУБЛИКС — опыт без потерь», тест стиля инвестора, результат простым языком — *есть* (v2 с вариантом «Г» во 2-м вопросе).
- **Обучение:** список уроков, ссылки — *есть*; контент уроков в `Теория.docx` намного богаче — переносить поэтапно в `data.js` / отдельные экраны.
- **Новости:** список + статья — *есть*.
- **Отчёт родителю** — *есть* (демо).
- **Мини-игры (хаб)** — *есть*; состав игр не совпадает с полным списком из геймификации — см. часть B.
- **Бумага:** график, таймфреймы, покупка — *частично*; вкладки стакан / дивиденды / новости / события — **фаза 2+**.
- **Портфель / несколько портфелей** — в документе запрошено; веб — один портфель; мультипортфели — **фаза 2+** ([`BACKLOG.md`](../BACKLOG.md)).
- **Аналитика, операции, избранное, сделка (лимиты/отложенные)** — **фаза 2+** с приоритетом после стабильного MVP торговли.

### Формулировки для подростков

- Избегать сухих подписей вроде «сортировка по |Δ%| к открытию»; заголовки в духе «Кто сегодня зажигает на бирже?» / «Самые заметные бумаги».

## Часть B. Мини-игры и геймификация (документ «описание мини-игр…»)

### B1. Викторина (MVP по документу)

| Параметр | По документу |
|----------|----------------|
| Раунд | 10 вопросов, 20 с, 3 ответа (рост / падение / без изменений) |
| Победа | ≥70% |
| Лимит | 5 игр/день |
| Банк | 50 вопросов (30 новости / 20 графики — в ТЗ) |
| Экраны | `quiz_entry`, `quiz_game`, `quiz_result` |
| API | `POST /api/game/quiz/complete` |
| Ассеты | SVG ↗ ↘ → 32×32, без эмодзи в UI кнопок |

**Веб:** реализовано ядро; добить: награды по таблице (победа / участие / идеал / быстрые ответы), подсветка верного ответа, время на пояснение, иконки SVG, логирование аналитики (опционально).

### B2. Биржа-хаос

Отдельный виртуальный портфель, события 24–72 ч, `chaos_portfolios`, cron — **эпик фазы 2** (не смешивать с основным портфелем).

### B3. Торговый спринт

5 вопросов, кнопки КУПИТЬ / ПРОДАТЬ / ДЕРЖАТЬ, скорость, комбо, 30 ситуаций, лимит 5/день, API `sprint/complete` — **новая игра**; оценка после викторины и стабилизации портфеля.

### B4. Инвестиционный пазл

Drag-and-drop, 5 заданий, сектора/компании — **фаза 2** (сложность UI + валидация).

### B5. Покупай низко — продавай высоко

60 с, график MOEX, 1 сделка, цель ≥20% прибыли — **новая игра** или упростить до прототипа.

### B6. Портфельный конструктор

Бюджет, 6–10 акций, правила диверсификации, оценка A–F — **фаза 2**.

### B7. Вперёд, инвестор!

Endless runner — **есть** в вебе; сверить награды (монеты → XP/Рубликсы) с таблицей документа.

### Прочее из того же файла

- **Финансовый выбор** — аналог ситуаций с пояснениями; в вебе есть «choice».
- **Раг пул** — есть.
- **Геймификация:** XP и Рубликсы раздельно, уровни 1–10, достижения (15 в MVP), стрик, ежедневные квесты ×3, рейтинги — внедрять **слоями**: сначала отображение XP/рубликсов и викторина, затем квесты и достижения.
- **Аватар:** слоты голова/тело/аксессуар/рамка — частично есть кастомизация; расширение по таблице документа — фаза 2.

## Часть C. «Теория.docx»

### C1. Входной тест

- **v1:** A/B/В по вопросам, сумма 6–18, уровни 6–9 / 10–14 / 15–18, тексты тостов — совпадает с логикой веба (v2 с 4 вариантами во 2-м вопросе и баллом «Г» = 4).

### C2. Дневной тест

- 5 вопросов в документе с полными пояснениями; механика «ошибка +10 сек» — можно добавить как отдельный режим от викторины рынка.
- Архитектура: единый банк с тегами Level 1–3, 4+1 вопрос, адаптивность — **целевое состояние**; MVP: статический набор по уровню из входного теста.

### C3. Контент обучения

- Модули «Старт», «Как устроена биржа», «Что покупают», рынки МОЕХ и т.д. — большой объём; перенос в приложение **порциями** (markdown/HTML в data или отдельные JSON), с tone of voice «для подростков + юмор».

## Часть D. Технические и продуктовые требования (сквозные)

1. **Котировки:** периодическое обновление (15–30 с), пауза при скрытой вкладке; честное UX про задержку данных MOEX.
2. **Портфель на пользователя:** ключи хранилища по id пользователя + синхронизация с сервером при авторизации (`GET/PATCH /api/portfolio`).
3. **Квиз и викторина:** подсветка правильного ответа, достаточное время на чтение пояснения.
4. **Иконки:** SVG / спрайт, **не эмодзи** на кнопках и карточках игр.
5. **Сортировка акций:** единая логика; на экране «Все акции» — переключатель (например по движению / по алфавиту).

## Рекомендуемый порядок работ (обновлённый)

1. Сквозные: изоляция портфеля, polling котировок, копирайт главной, квиз/викторина UX, SVG-иконки, сортировка списка акций.  
2. Викторина: награды по таблице документа, при необходимости расширение банка под 50 вопросов с типами.  
3. Дневной тест (5 вопросов из `Теория.docx`) как отдельный экран или режим.  
4. Мини-игры новые: Торговый спринт → Покупай низко → Пазл → Конструктор (по приоритету заказчика).  
5. Экраны бумаги (вкладки), аналитика, операции, избранное — по [`BACKLOG.md`](../BACKLOG.md) и ресурсам.  
6. Геймификация: уровни 1–10, достижения, квесты ×3, стрик — итерации после ядра игр.
