# Рубликс Web — единый план (источники + бэклог + полировка)

Этот документ **объединяет**:

1. **[PLAN_WEB_IZ_NEW_DATA.md](PLAN_WEB_IZ_NEW_DATA.md)** — экраны MVP, мини-игры, «Теория», токены дизайна, фазы.
2. **[BACKLOG.md](../BACKLOG.md)** — фаза 2+: Биржа-хаос, стакан, мультипортфели, аналитика, дневной тест, «комната героя».
3. **Сквозная полировка веб-MVP** — изоляция данных пользователя, API портфеля, котировки, копирайт, UX викторины, иконки, сортировка списка акций.

---

## Статус реализации (живой чеклист)

- [x] Префиксы `localStorage` по пользователю (`id` / `email` / `anon`), чтение со старыми ключами для миграции.
- [x] `GET/PATCH /api/portfolio` + колонка `portfolio_json` в `user_stats`, синк при входе и после сделок (при бэкенде).
- [x] Интервальное обновление котировок (~25 с), пауза при скрытой вкладке, метка «Котировки обновлены».
- [x] Подростковый блок топ-бумаг на главной (без сухого подзаголовка про сортировку).
- [x] Викторина: подсветка верного ответа, больше времени на пояснение, без эмодзи в тексте пояснения.
- [x] Карточки игр: SVG-иконки по `iconId` вместо эмодзи.
- [x] Экран «Все акции»: переключатель сортировки (движение / по алфавиту).

Детальная разбивка экранов 1–15 по фазам: **[SCREEN_SPEC_PHASES.md](SCREEN_SPEC_PHASES.md)**.

Дальше по [PLAN_WEB_IZ_NEW_DATA.md](PLAN_WEB_IZ_NEW_DATA.md): дневной тест, новые мини-игры, полный стакан/дивиденды, геймификация уровней/квестов.

## Архитектура (кратко)

| Слой | Файлы |
|------|--------|
| UI / навигация | `web/js/app.js`, `web/index.html` |
| Данные и хранение | `web/js/data.js`, `web/js/db.js` (SQLite в браузере) |
| MOEX | `web/js/api.js` |
| API | `server/server.js`, `server/db.js` |

---

## Регрессия (ручная)

1. Регистрация / вход / выход (бэкенд и локальный режим).
2. Главная: баланс, портфель, топ бумаг, обновление котировок.
3. Покупка / продажа; при бэкенде — обновление страницы и повторный вход (портфель с сервера).
4. Викторина: ответы, пояснения, лимит 5/день.
5. «Все акции»: обе сортировки, переход на график.
