# Сверка с «Документ с основными правками по мвп»

> Актуализация 2 ноября 2026: текущие решения описаны в [UX_MVP.md](UX_MVP.md).
> Ниже сохранена сверка исходного объёма. Выплаты дивидендов и фундаментальная
> отчётность в текущем MVP не подключены; полный стакан требует доступа MOEX.

Источник: `New data/Документ с основными правками по мвп.docx` (текст извлечён для сверки с **web** MVP).

Условные обозначения: ✅ сделано в веб-демо · ⚠️ частично / упрощено · ⏳ вне текущего MVP (заложено текстом или позже)

## Экран портфеля (главная)

| Требование | Статус |
|------------|--------|
| Счёт, доходность, операции, аналитика | ✅ |
| Кнопка заработка/пополнения → квесты/обучение | ⚠️ Нет реального пополнения (осознанно). **Добавлена** кнопка **«Заработок»** на карточке портфеля → экран обучения (уроки, квесты, рубликсы). |
| Баланс, переключение за день / за всё время | ✅ |
| Чипы инструментов (акции, облигации…) | ⚠️ Акции TQBR; остальные — заглушка с пояснением. |
| Сторис | ✅ |
| Позиции в портфеле, переход на бумагу | ✅ |
| Избранное, бумаги, аналитика, операции | ✅ |
| Поиск ЦБ | ⚠️ Нет строки в шапке; **ссылка «Поиск»** в блоке «Акции» → экран всех акций с фокусом в поле поиска. |
| Несколько портфелей и создание | ✅ (лимиты по тарифу) |

## Экран ценной бумаги

| Требование | Статус |
|------------|--------|
| Название, тикер, избранное, шаринг | ✅ |
| Цена, график, таймфреймы | ✅ (таймфреймы по тарифу) |
| Описание эмитента | ✅ |
| Видео/карточки эмитента | ⚠️ Блок + кнопка «Скоро», по клику — пояснение. |
| Финансовые показатели | ⚠️ Вместо вымышленных показателей показаны реальные параметры торгов MOEX. Фундаментальная отчётность не подключена. |
| Купить / продать | ✅ |
| Стакан | ⚠️ Требуется отдельный доступ MOEX. Вкладка объясняет ограничение; вымышленных заявок нет. |
| Дивиденды: дата, сумма, **доходность** | ⏳ Выплаты не начисляются. Учебный календарь удалён; механизм объяснён текстом. |
| Облигации / купоны визуально | ⏳ Нет отдельного режима облигаций. |
| Новости по бумаге | ✅ |
| События с датой; счёт при мультипортфеле | ✅ Показ тега счёта, если есть `portfolioId`. |

## Аналитика

| Требование | Статус |
|------------|--------|
| Переключатель портфелей, по умолчанию «все» | ✅ По умолчанию **«Все счета»**; можно переключить на **«Активный счёт»**. |
| График доходности, таймфреймы, доход за период | ⏳ Блок **«По ТЗ (следующие итерации)»** внизу экрана. |
| Будущие выплаты, структура по отраслям/валютам | ⏳ То же. |
| Круговая структура (акции) | ✅ |
| Снимки раз в день | ✅ |
