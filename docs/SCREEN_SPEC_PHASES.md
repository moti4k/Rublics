## Сортировка «топ движений»

Список упорядочивается по **убыванию модуля дневного изменения %** (самое «заметное» движение), затем по знаковому %, затем по тикеру. Подзаголовок на главной это дублирует; при смене логики — обновить `sortTopMoversList` в `app.js`.
