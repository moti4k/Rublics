# Rubliks Web — бэклог фазы 2+

Сводный план и чеклист MVP: [docs/MASTER_PLAN.md](docs/MASTER_PLAN.md).

Задачи из MVP-документов, сознательно вынесенные за пределы текущего веб-MVP (объём / отдельный бэкенд).

## Биржа-хаос

- Отдельный виртуальный портфель, события на горизонте 24–72 ч.
- Серверный cron, таблица `chaos_portfolios` (или аналог), **не смешивать** с основным портфелем пользователя.
- Оценка и спецификация API после стабилизации викторины и базовой геймификации.

## Биржевой стакан

- Вкладка/экран стакана заявок у бумаги, потоковые или псевдо-потоковые данные.
- Зависит от выбора источника данных и макета экрана бумаги.

## Мультипортфели

- Несколько именованных портфелей, переключение, агрегация в аналитике.
- Миграции локального `rubliks_portfolio` и синхронизация с бэкендом.

## Полная аналитика

- Расширенные графики, метрики, сравнение с индексами — отдельный эпик.
